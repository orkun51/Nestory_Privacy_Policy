# Nestory Privacy Policy

This repository hosts the **Privacy Policy** for the Nestory app.

- **Full policy (Markdown):** [PRIVACY_POLICY.md](PRIVACY_POLICY.md)
- **Web version (GitHub Pages):** After enabling Pages, use **https://orkun51.github.io/Nestory_Privacy_Policy/**

Use the Pages URL in **App Store Connect** (Privacy Policy URL) and in the app if you add a "Privacy Policy" link.

---

## How to add this to GitHub

1. Create or open the repo: [github.com/orkun51/Nestory_Privacy_Policy](https://github.com/orkun51/Nestory_Privacy_Policy)
2. Upload (or copy) these files into the **root** of the repo:
   - `index.html` — web page for GitHub Pages
   - `PRIVACY_POLICY.md` — full policy in Markdown
   - `README.md` — this file

---

## Enable GitHub Pages (to get a live URL)

1. On GitHub: **Settings** → **Pages**
2. Under **Source**, choose **Deploy from a branch**
3. Branch: **main** (or **master**), folder: **/ (root)**
4. Click **Save**
5. After 1–2 minutes, the policy will be at: **https://orkun51.github.io/Nestory_Privacy_Policy/**

---

## Updating the policy

Edit `PRIVACY_POLICY.md` and/or `index.html`, then commit and push. GitHub Pages will update automatically.
